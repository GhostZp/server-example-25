# Introduction
This is the backend to a fullstack website.

# Installation
1. Clone the repository
2. Open the project in your IDE.
3. Create an empty MariaDB database.
4. Configure the database connection in db/health-diary-db.sql
5. Run the application using npm run dev.
6. Open the browser and go to http://localhost:3000.
7. BackEnd is now running.

# Instructions
1. Run the application
2. Register a new account or log in if you already have an account. You need to be logged in, in order to look at your own diaryentries and user information.
3. Home page displays information about the website.
4. In the diary page you can log new diaryentries and browse old diaryentries.
5. In the BMI page you can calculate your BMI and get information about it.
6. The profile page allows you to look at your information and change your information.
7. These introduction are subject to change when the website changes.
